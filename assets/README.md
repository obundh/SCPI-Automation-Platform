# Application icon provenance

`scpi-automation-platform.ico` is an original project-owned geometric icon
created for this repository on 2026-07-26. It uses only drawn rounded
rectangles and a generic measurement waveform. It does not copy a
manufacturer logo, product photograph, instrument front panel, manual image,
or third-party icon.

The tracked ICO contains the common Windows icon sizes from 16×16 through
256×256 pixels. The same file is embedded in the PyInstaller application,
used for the Tk window, and used by the Inno Setup installer.
