   일치해도 각 SCPI operation을 실장비에서 검증하기 전에는 실행 기능이
   열리지 않습니다.
4. RF 출력·전압·전류·전력 등 위험 명령은 장비 정격, DUT 한계, 배선과
   안전 종료 수단을 확인한 뒤 사용하세요.
