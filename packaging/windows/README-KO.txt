계측기 연결 도우미 · Windows 사용 안내
=========================================

바로 시작하기
-------------

1. 시작 메뉴 또는 바탕화면에서 "계측기 연결 도우미"를 실행하세요.
2. 처음에는 "데모 장비 4대로 둘러보기"를 눌러 화면을 익히세요.
3. 실제 장비를 찾을 때만 시험 PC의 VISA 통신 드라이버가 필요할 수 있습니다.

이 실행파일에는 Python, Tk 화면 구성요소, PyVISA와 Excel 저장 구성요소가
포함되어 있습니다. Python을 따로 설치할 필요가 없고 인터넷 없이 실행됩니다.

실제 장비가 보이지 않을 때
---------------------------

VISA는 PC와 계측기가 대화하는 통로입니다. NI-VISA, Keysight IO Libraries,
R&S VISA 등 시험실에서 사용하는 VISA 런타임이 PC에 설치돼 있는지 확인하세요.
제조사 VISA DLL과 설치 프로그램은 재배포 허가 문제 때문에 이 설치본에 들어
있지 않습니다. 여러 VISA를 무작정 설치하기보다 시험실에서 이미 사용하는
제품 또는 장비 제조사가 안내하는 공식 런타임을 우선하세요.

프로그램의 "1. 장비 찾기" 화면은 검색 실패 원인에 따라 "이렇게 해보세요"
안내를 제공합니다. VISA를 설치한 뒤에는 프로그램을 다시 실행하세요.

안전하게 사용하기
------------------

- 모델명이 일치해도 각 SCPI operation을 실장비에서 확인하기 전에는 실행
  기능이 열리지 않습니다.
- 먼저 데모와 Dry Run으로 장비, 값, 순서와 안전 종료를 확인하세요.
- RF 출력·전압·전류·전력 등 위험 명령은 장비 정격, DUT 한계, 배선과
  실제 비상정지 수단을 확인한 뒤 사용하세요.
- 이 GitHub 빌드의 자동 검사는 실제 계측기 연결 검증을 대신하지 않습니다.
